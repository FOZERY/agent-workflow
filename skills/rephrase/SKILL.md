# Rephrase

Restate your last reply to the user.

- Keep every fact, number, decision and open question from it.
- Use the words that a developer says out loud. Replace or explain each term that the user may not know.
- Make it shorter: the main point first, one idea per sentence.
- Use the language of the reply.
- If the `writing-for-people` skill is installed, follow it.

Reply with the new version only.
